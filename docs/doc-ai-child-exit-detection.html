👶 智能门锁儿童离家守护 — 提示词工程方案

基于萤石/小米/华为/Veise等行业竞品对标，结合GPT-4V隐私伦理与arxiv儿童数据集研究，设计覆盖"门内开门触发→身高估算+多信号融合→伴随关系分析→推送决策→多帧时序确认"全链路的儿童离家安全守护提示词方案。

方案概述

当门从内侧被打开时，猫眼抓拍门前图像，通过AI视觉模型进行儿童检测。若判定为儿童独自离家，则触发家长推送提醒，防止儿童走失或独自外出发生意外。本方案的核心挑战在于：精准判定儿童身份（非年龄识别）、区分独自出门与成人陪同、儿童图像隐私合规。

五层检测流程设计

第一层：人形存在性 → 第二层：数量与伴随 → 第三层：儿童身份判定 → 第四层：出门方向与独立性 → 第五层：推送决策

第一层：人形存在性检测

  • 判断画面中是否存在人形
  • 若无人形 → 输出"无人出门"，终止流程，不推送
  • 若存在人形 → 进入第二层

第二层：人形数量与伴随关系检测

  • 识别人形数量
  • 若存在≥2个人形且距离相近（≤0.5m）→ 判定为"有成人伴随"，进入伴随判定分支
  • 若仅1个人形，或多人形但无伴随关系 → 进入第三层

第三层：儿童身份判定（核心层）

通过多信号融合判定是否为儿童，不依赖单一特征：

信号判定逻辑权重
身高估算≤1.1m→强儿童信号；1.1m~1.4m→弱儿童信号；>1.4m→非儿童信号0.45
体型比例头身比1:4~1:6(儿童) vs 1:7~1:8(成人)；四肢相对躯干较短；肩宽较窄0.25
衣着特征鲜艳色彩、卡通图案、校服标识、背书包（不可仅凭衣着判定）0.10
步态姿态步幅较小、重心偏低、可能有蹦跳/摇摆姿态0.10
面部区域面部轮廓圆润、五官比例偏大（严禁估算精确年龄，仅做二元辅助判定）0.10
🔐 融合判定规则：
加权得分 ≥ 0.70 → 儿童
加权得分 0.50~0.70 → 疑似儿童
加权得分 < 0.50 → 非儿童（成人/青少年）

身高估算参照校准

  • 标准门框高度：2.0m（可由安装配置校准）
  • 标准门锁高度：1.0m（可由安装配置校准）
  • 人形头顶到门锁位置的距离比例 → 推算身高
  • 身高估算为粗略推算，误差范围±0.15m，需结合其他信号综合判定

第四层：出门方向与独立性判定

  • 出门方向：已由门锁传感器确认"从内向外开门"
  • 独立性判定：
    • 画面中仅1个人形 → 独自出门
    • 画面中有成人伴随（身高>1.5m的人形在0.5m内） → 非独自出门
    • 画面中有另一儿童伴随 → 两名儿童独自出门
    • 人形正在被抱起/牵手的姿态 → 有成人陪同，非独自出门

第五层：推送决策

场景推送级别推送内容推送方式
儿童独自出门🔴 紧急"检测到儿童独自出门，请及时关注"APP推送+本地语音提醒
疑似儿童独自出门🟡 提醒"疑似儿童独自出门，请确认"APP推送
儿童有成人伴随出门🟢 知会"检测到儿童在成人陪同下出门"APP推送（可配置关闭）
非儿童出门⚪ 无—不推送

关键约束

误报抑制

⚠️ 以下场景不得触发儿童离家告警：
  • 成人出门（身高>1.4m，体型比例符合成人特征）
  • 青少年出门（身高>1.4m，虽未成年但体型接近成人）
  • 宠物出门（猫/狗，非人形）
  • 家长抱婴儿/幼儿出门（有成人伴随，非独自出门）
  • 家长牵儿童出门（有成人伴随）
  • 业主本人回家（门从外侧打开，本系统不激活）

漏报抑制

⚠️ 漏报代价远高于误报，临界case偏向推送：
  • 身材矮小的成人（1.4~1.5m）出门时，若体型/步态/衣着信号均指向成人 → 不触发（允许此边缘case）
  • 身高接近1.1m临界值的儿童 → 判定为"疑似儿童"，触发🟡提醒级推送

隐私保护（儿童图像属敏感数据）

🔐 儿童隐私保护约束：
  • ⚠️ 严禁估算精确年龄（如"约5岁"），仅输出"儿童/疑似儿童/非儿童"的二元/三元判定
  • ⚠️ 严禁识别儿童身份（不输出"这是XX的孩子"）
  • ⚠️ 严禁推断儿童情绪/状态
  • 推送消息中不附带原始抓拍图像，仅附带经脱敏处理的缩略图（人脸区域模糊化）
  • 原始图像仅在本地存储，加密保存，不上传云端（除非用户明确授权）
  • 脱敏缩略图保留时长≤24小时，超期自动删除

Few-Shot 示例

示例1：儿童独自出门（🔴紧急推送）

场景：早上8点，身高约1.0m的儿童独自开门外出，背着书包
推理链：门内开门→人形1个→身高约1.0m(强儿童信号)+头身比1:5(儿童)+鲜艳书包+小步幅→融合得分0.85→儿童→无伴随→独自出门→紧急推送
输出：is_child_verdict: "儿童" | push_level: "urgent" | should_local_voice: true

示例2：成人出门（⚪不推送）

场景：身高约1.65m的成人从门内开门外出
推理链：门内开门→人形1个→身高1.65m(非儿童)+头身比1:7.5(成人)+成人衣着→融合得分0.12→非儿童→不推送
输出：is_child_verdict: "非儿童" | push_level: "none"

示例3：家长抱儿童出门（🟢知会推送）

场景：成人(1.7m)怀抱幼儿(0.8m)出门
推理链：门内开门→人形2个且距离极近→伴随关系→儿童有成人伴随→知会级推送
输出：is_accompanied: true | push_level: "info"

示例4：夜间疑似儿童出门（🟡提醒推送）

场景：夜间红外模式，身高约1.15m的人形出门，体型偏小但红外细节受限
推理链：门内开门→身高1.15m(临界值)+体型偏小→红外模式误差扩大→融合得分0.62→疑似儿童→提醒级推送
输出：is_child_verdict: "疑似儿童" | push_level: "warning"

示例5：宠物出门（⚪不推送）

场景：门内开门，一只小型犬从门缝跑出
推理链：门内开门→非人形生物(四足,体型不符)→无人形→不推送
输出：has_human: false | push_level: "none"

多帧时序确认模块

单帧检测的连续输出送入时序确认模块，降低误报率：

出门确认

  • 门内开门事件后，连续3帧（间隔500ms）均检测到同一儿童人形在门外 → 确认儿童已出门
  • 若仅1帧检测到儿童，后续帧无人形 → 可能是误触发（如儿童开门后未出门），取消推送

伴随确认

  • 单帧判定"独自出门"，但后续帧出现成人伴随 → 升级为"有成人陪同"，降级推送
  • 单帧判定"有成人伴随"，但成人随后返回门内 → 升级为"儿童独自出门"，升级推送

去重防扰

  • 同一儿童出门事件，5分钟内不重复推送
  • 儿童出门后5分钟内回家 → 补充推送"儿童已回家"
