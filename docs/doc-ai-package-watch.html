📦 智能门锁快递/外卖看护 — 提示词工程方案

基于萤石/小米/TCL/凯迪仕/德施曼等行业竞品对标，结合双摄硬件架构与VLM多模态融合实践，设计覆盖"物品识别分类→配送员行为意图识别→时序状态机管理→异常挪动告警→无接触取件联动→每日异常集锦"全链路的门前物品看护提示词方案。

方案概述

智能门锁作为家庭入户的第一道防线，具备"门前必经"的天然监控优势。随着电商与外卖的普及，快递/外卖的门前安全看护已成为用户核心痛点——包裹丢失、外卖被偷、生鲜变质等问题频发。本方案将门锁从简单的猫眼监控升级为AI门前物品看护系统，利用双摄硬件（上摄看人+下摄看地面），实现对快递/外卖物品的"送达→放置→在位→异常挪动→取走"全生命周期看护。

第四层：时序状态机

每个被看护物品维护独立的状态机，实现全生命周期追踪：

空地 → 物品出现+配送员放置 → 物品送达 → APP推送"物品已送达"

物品送达 → 物品持续在位 → 物品在位 → 定时提醒(超时未取)

物品在位 → 住户取走 → 正常取走 → APP推送"物品已取走"

物品在位 → 陌生人拿走 → 异常挪动 → 紧急告警"物品被陌生人拿走"

物品在位 → 物品位置变化 → 物品位移 → APP推送"物品被移动"

物品在位 → 物品消失+无人 → 疑似丢失 → 紧急告警"物品疑似丢失"

关键约束

误报抑制

✅ 以下场景不得触发物品看护告警：
  • 猫/狗在门前活动（非人形，不触发物品变化分析）
  • 落叶/纸片/塑料袋被风吹到门前（非目标物品）
  • 住户自己从门内拿出物品放置（如放垃圾袋出门→非看护物品）
  • 邻居经过门前（无人触碰物品）
  • 门前固定物品(地垫/鞋架/置物架)的位置微调
  • 光线变化导致的画面整体亮度变化
  • 雨雪天气中的雨滴/积雪覆盖物品表面（物品仍在位）
  • 昆虫/蜘蛛贴附镜头导致的画面遮挡

漏报抑制

⚠️ 以下场景必须触发告警：
  • 夜间配送员放置快递/外卖（红外模式，降低置信度阈值）
  • 配送员快速放下物品后立即离开（行为时间<3秒）
  • 多个物品同时送达（如多个快递包裹叠放）
  • 物品被部分遮挡（如包裹被花盆挡住一部分）
  • 陌生人拿走物品后快速离开画面（抓拍+人物特征记录）

隐私保护

  • 配送员面部需脱敏处理（推送缩略图中模糊化）
  • 不记录/不上传配送员的身份信息
  • 住户取走物品的画面仅本地存储，不上传云端
  • 推送消息中不包含可识别个人身份的描述
  • 异常挪动事件的人物描述仅限：身高范围、衣着颜色、大致体型——严禁推断身份

置信度要求

场景置信度范围处理策略
物品分类 < 0.50低标记为"未识别物品"，按看护物品处理(保守策略)
物品分类 0.50-0.70中标记为"疑似XX"，推送时标注"疑似"
物品分类 ≥ 0.70高正常分类
行为识别 < 0.50低标记为"不确定"，按保守策略处理
夜间红外模式—物品分类置信度下限降至0.40

联动能力

无接触取件联动（德施曼方案升级）

当检测到外卖/快递送达时，根据用户是否在家生成差异化联动建议：

场景用户状态联动动作
外卖送达用户在家本地语音提醒"外卖已放门口，请尽快取餐"
外卖送达用户不在家APP推送 + 建议远程查看 + 设置临时取件提醒
快递送达用户在家APP推送 + 可选本地语音
快递送达用户不在家APP推送 + 远程查看抓拍 + 可选"远程开锁让家人代取"
陌生人拿走物品—立即APP推送 + 本地声光告警 + 录制10s视频片段
外卖超15分钟未取—APP推送 + 本地语音提醒

每日异常短视频集锦（TCL方案升级）

将当天门前物品相关的异常事件浓缩为短视频集锦，仅包含异常事件（物品送达仅首次、异常挪动、疑似丢失、超时未取），排除正常事件。每个事件截取3-5秒关键片段，总时长≤3分钟，并生成文字摘要供用户快速浏览。

总结

本方案完整覆盖了从双摄场景变化检测→物品识别分类→配送员行为意图识别→时序状态机管理→推送决策→无接触取件联动→每日异常集锦的全链路，对标萤石/小米/TCL/凯迪仕/德施曼行业最新能力并实现系统性升级。

📦 核心价值：
  • 双摄协同：上摄看人+下摄看地面，解决单摄无法同时覆盖的痛点
  • 语义理解：从"检测包裹"升级为"理解门口场景"——判断快递送达/外卖送达/偷窃行为
  • 全生命周期：5状态时序状态机，覆盖送达→在位→异常→取走全流程
  • 外卖专项：15分钟超时提醒+食品变质预警+偷外卖精准捕获
  • 无接触取件：德施曼方案升级，远程查看+远程开锁+外卖柜联动
  • 误报抑制：12项排除规则，TCL方案验证准确率提升70%

本方案可直接用于智能门锁产品的快递/外卖看护模块设计与VLM(Qwen2-VL/GPT-4o等)的Prompt配置落地。
