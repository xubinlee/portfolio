租户模型设计

1. 四级组织架构

L0 平台（Platform） SaaS 运营方，管理所有租户、全局配置、计费 超管
L1 租户（Tenant） 品牌/企业，如「如家酒店」「自如公寓」 租户管理员
L2 门店（Store） 物理经营场所，如「如家北京望京店」 店长
L3 楼栋/楼层（Building） 门店下的物理分区，如「A栋3层」 楼层管理员

数据隔离设计

1. 隔离策略选型

策略隔离级别成本适用场景本方案选择
独立数据库物理隔离最高金融/政务否
共享数据库、共享 Schema行级隔离最低轻量 SaaS否
共享数据库、独立 SchemaSchema 隔离中等中型 SaaS否
共享库 + tenant_id 行级隔离逻辑隔离较低IoT SaaS✓ 采用
选型理由
IoT SaaS 场景下，设备数据量大（时序数据）、租户数量可控（百级）、查询模式统一。采用共享库 + tenant_id 行级隔离，配合 MyBatis-Plus TenantLineInnerInterceptor 自动注入租户条件，兼顾成本与安全性。对安全要求极高的租户，可升级为独立 Schema 方案。

2. 租户上下文自动注入

/** MyBatis-Plus 租户拦截器 — 自动注入 tenant_id 条件 */
@Component
public class TenantLineInnerInterceptor extends JsqlParserSupport implements InnerInterceptor {

    private final TenantLineHandler tenantLineHandler;

    @Override
    public Expression buildTableExpression(Table table, Expression where) {
        // 对需要隔离的表自动追加 tenant_id = ?
        if (tenantLineHandler.ignoreTable(table.getName())) {
            return null;
        }
        return new EqualsTo(
            new Column(tenantLineHandler.getTenantIdColumn()),
            tenantLineHandler.getTenantId()
        );
    }
}

/** 租户上下文持有者 — 基于 ThreadLocal */
public class TenantContextHolder {

    private static final ThreadLocal<Long> TENANT_HOLDER = new ThreadLocal<>();

    public static void setTenantId(Long tenantId) {
        TENANT_HOLDER.set(tenantId);
    }

    public static Long getTenantId() {
        return TENANT_HOLDER.get();
    }

    public static void clear() {
        TENANT_HOLDER.remove();
    }
}

/** 租户上下文过滤器 — 从 Token 中提取租户ID */
@Component
public class TenantContextFilter implements Filter {

    @Override
    public void doFilter(ServletRequest req, ServletResponse res, FilterChain chain) {
        HttpServletRequest request = (HttpServletRequest) req;
        String token = request.getHeader("Authorization");

        if (token != null && token.startsWith("Bearer ")) {
            // 从 JWT Token 中解析租户ID
            Claims claims = JwtUtil.parseToken(token.substring(7));
            Long tenantId = claims.get("tenantId", Long.class);
            TenantContextHolder.setTenantId(tenantId);
        }

        try {
            chain.doFilter(req, res);
        } finally {
            TenantContextHolder.clear();
        }
    }
}

3. MQTT Topic 租户隔离

MQTT Topic 设计天然支持租户隔离，通过 Topic 前缀区分不同租户的设备：

/** MQTT Topic 租户隔离规则 */
//
// Topic 层级设计：
//   /{industry}/{tenantCode}/{storeCode}/lock/{deviceId}/{direction}/{type}
//
// 示例：
//   /hotel/RUJIA/BJ-WANGJING/lock/LOCK-001/up/event      如家望京店设备上报
//   /hotel/RUJIA/BJ-WANGJING/lock/LOCK-001/down/cmd       如家望京店指令下发
//   /apartment/ZIRU/SH-PUDONG/lock/LOCK-002/up/alive     自如浦东店心跳
//   /homestay/TUJIA/HZ-XIHU/lock/LOCK-003/up/alarm       途家西湖店告警
//
// EMQX ACL 规则 — 设备只能访问自己租户+门店的 Topic
//   允许: /hotel/RUJIA/BJ-WANGJING/lock/LOCK-001/#
//   禁止: /hotel/RUJIA/SH-PUDONG/lock/#  （跨门店）
//   禁止: /hotel/HILTON/#                （跨租户）

public class TenantTopicResolver {

    private static final Pattern TOPIC_PATTERN = Pattern.compile(
        "/(\\w+)/(\\w+)/(\\w+)/lock/([\\w-]+)/(up|down)/(\\w+)"
    );

    public TopicInfo resolve(String topic) {
        Matcher m = TOPIC_PATTERN.matcher(topic);
        if (!m.matches()) throw new IllegalArgumentException("非法 Topic");

        return new TopicInfo(
            m.group(1),  // industry
            m.group(2),  // tenantCode
            m.group(3),  // storeCode
            m.group(4),  // deviceId
            m.group(5),  // direction
            m.group(6)   // type
        );
    }

    public String buildTopic(String industry, String tenantCode,
                           String storeCode, String deviceId,
                           String direction, String type) {
        return String.format("/%s/%s/%s/lock/%s/%s/%s",
            industry, tenantCode, storeCode, deviceId, direction, type);
    }
}

批量门锁管理

1. 批量设备绑定

新门店开业时，需将数百把门锁批量绑定到门店+房间：

/** 批量设备绑定服务 */
@Service
public class BatchDeviceBindService {

    @Transactional
    public BatchBindResult batchBind(BatchBindRequest request) {
        Long tenantId = TenantContextHolder.getTenantId();
        String storeCode = request.getStoreCode();

        // 1. 校验门店归属
        Store store = storeRepo.findByTenantIdAndCode(tenantId, storeCode);
        if (store == null) {
            throw new BusinessException("门店不存在或不属于当前租户");
        }

        // 2. 校验设备数量限制
        int currentCount = deviceRepo.countByTenantId(tenantId);
        Tenant tenant = tenantRepo.getById(tenantId);
        if (currentCount + request.getDevices().size() > tenant.getMaxDevices()) {
            throw new BusinessException("超出套餐设备数量限制");
        }

        // 3. 批量绑定
        List<DeviceBindItem> items = request.getDevices();
        List<String> successIds = new ArrayList<>();
        List<BindFailure> failures = new ArrayList<>();

        for (DeviceBindItem item : items) {
            try {
                // 3.1 校验设备是否已绑定
                Device existing = deviceRepo.findByDeviceId(item.getDeviceId());
                if (existing != null && existing.getTenantId() != null) {
                    failures.add(new BindFailure(item.getDeviceId(), "设备已绑定"));
                    continue;
                }

                // 3.2 绑定设备到租户+门店+房间
                Device device = Device.builder()
                    .deviceId(item.getDeviceId())
                    .tenantId(tenantId)
                    .storeCode(storeCode)
                    .buildingCode(item.getBuildingCode())
                    .roomCode(item.getRoomCode())
                    .roomName(item.getRoomName())
                    .bindAt(Instant.now())
                    .status(DeviceStatus.BOUND)
                    .build();
                deviceRepo.save(device);

                // 3.3 更新 MQTT ACL 规则
                mqttAclService.updateDeviceAcl(device);

                successIds.add(item.getDeviceId());
            } catch (Exception e) {
                failures.add(new BindFailure(item.getDeviceId(), e.getMessage()));
            }
        }

        return new BatchBindResult(successIds.size(), failures);
    }
}

2. 批量指令下发

酒店退房时，需批量重置门锁密码；公寓换租时，需批量下发新指纹。批量指令采用异步任务 + 进度追踪模式：

/** 批量指令下发服务 */
@Service
public class BatchCommandService {

    public BatchTask submitBatchCommand(BatchCommandRequest request) {
        Long tenantId = TenantContextHolder.getTenantId();

        // 1. 解析目标设备列表
        List<String> deviceIds = resolveTargetDevices(tenantId, request);

        // 2. 创建批量任务
        BatchTask task = BatchTask.builder()
            .taskId(UUID.randomUUID().toString())
            .tenantId(tenantId)
            .command(request.getCommand())
            .totalCount(deviceIds.size())
            .successCount(0)
            .failCount(0)
            .status(BatchTaskStatus.PENDING)
            .build();
        batchTaskRepo.save(task);

        // 3. 分片异步执行（每片 50 台设备）
        Lists.partition(deviceIds, 50).forEach(chunk -> {
            asyncTaskExecutor.execute(() -> {
                for (String deviceId : chunk) {
                    try {
                        mqttCommandService.sendCommand(
                            tenantId, deviceId, request.getCommand(), request.getParams()
                        );
                        batchTaskRepo.incrementSuccess(task.getTaskId());
                    } catch (Exception e) {
                        batchTaskRepo.incrementFail(task.getTaskId());
                    }
                }
            });
        });

        return task;
    }

    public BatchTaskProgress getProgress(String taskId) {
        return batchTaskRepo.getProgress(taskId);
    }
}

2. 数据范围控制

/** 数据范围注解 — 控制接口返回的数据范围 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface DataScope {
    /** 数据范围类型 */
    ScopeType value() default ScopeType.TENANT;

    enum ScopeType {
        PLATFORM,   // 全平台数据
        TENANT,     // 本租户数据
        STORE,      // 本门店数据
        BUILDING,   // 本楼栋数据
        ROOM        // 本房间数据
    }
}

/** 数据范围切面 — 自动注入查询条件 */
@Aspect
@Component
public class DataScopeAspect {

    @Before("@annotation(dataScope)")
    public void before(JoinPoint jp, DataScope dataScope) {
        Long tenantId = TenantContextHolder.getTenantId();
        Long storeId = StoreContextHolder.getStoreId();
        String role = SecurityContextHolder.getRole();

        switch (dataScope.value()) {
            case TENANT -> QueryHelper.injectCondition("tenant_id", tenantId);
            case STORE  -> QueryHelper.injectCondition("tenant_id", tenantId)
                             .and("store_id", storeId);
            case BUILDING -> QueryHelper.injectCondition("tenant_id", tenantId)
                             .and("store_id", storeId)
                             .and("building_code", BuildingContextHolder.get());
            case ROOM -> QueryHelper.injectCondition("tenant_id", tenantId)
                             .and("room_code", RoomContextHolder.get());
            default -> {}
        }
    }
}

2. 策略模式实现业态差异

/** 业态策略接口 */
public interface IndustryStrategy {

    /** 入住开锁授权 */
    UnlockAuthorization authorizeCheckIn(CheckInRequest request);

    /** 退房/退租处理 */
    CheckOutResult processCheckOut(CheckOutRequest request);

    /** 临时授权（保洁/维修） */
    TempAuthResult grantTempAccess(TempAuthRequest request);
}

/** 酒店业态策略 */
@Service
public class HotelIndustryStrategy implements IndustryStrategy {

    @Override
    public UnlockAuthorization authorizeCheckIn(CheckInRequest request) {
        // 酒店模式：入住时生成临时密码，退房后自动失效
        String tempPassword = PasswordGenerator.randomDigits(6);
        LocalDateTime expireAt = request.getCheckOutTime();

        // 下发临时密码到门锁
        mqttCommandService.sendCommand(request.getTenantId(),
            request.getDeviceId(), "ADD_PASSWORD",
            Map.of("password", tempPassword,
                   "expireAt", expireAt.toString()));

        return new UnlockAuthorization(tempPassword, expireAt);
    }

    @Override
    public CheckOutResult processCheckOut(CheckOutRequest request) {
        // 酒店模式：退房时删除临时密码 + 重置门锁
        mqttCommandService.sendCommand(request.getTenantId(),
            request.getDeviceId(), "DELETE_PASSWORD",
            Map.of("passwordId", request.getPasswordId()));

        mqttCommandService.sendCommand(request.getTenantId(),
            request.getDeviceId(), "RESET_LOCK", Map.of());

        return CheckOutResult.ok();
    }
}

/** 公寓业态策略 */
@Service
public class ApartmentIndustryStrategy implements IndustryStrategy {

    @Override
    public UnlockAuthorization authorizeCheckIn(CheckInRequest request) {
        // 公寓模式：绑定租户指纹，租约期内有效
        mqttCommandService.sendCommand(request.getTenantId(),
            request.getDeviceId(), "ADD_FINGERPRINT",
            Map.of("userId", request.getUserId(),
                   "fingerIndex", request.getFingerIndex(),
                   "expireAt", request.getLeaseEnd().toString()));

        return new UnlockAuthorization("FINGERPRINT", request.getLeaseEnd());
    }

    @Override
    public CheckOutResult processCheckOut(CheckOutRequest request) {
        // 公寓模式：退租时删除指纹 + 清空授权
        mqttCommandService.sendCommand(request.getTenantId(),
            request.getDeviceId(), "DELETE_FINGERPRINT",
            Map.of("fingerIndex", request.getFingerIndex()));

        return CheckOutResult.ok();
    }
}

租户计费与配额

/** 租户配额校验服务 */
@Service
public class TenantQuotaService {

    public void checkDeviceQuota(Long tenantId) {
        Tenant tenant = tenantRepo.getById(tenantId);
        int current = deviceRepo.countByTenantId(tenantId);

        if (current >= tenant.getMaxDevices()) {
            throw new QuotaExceededException(
                "设备数量已达上限 (" + tenant.getMaxDevices() + ")，请升级套餐");
        }
    }

    public void checkStoreQuota(Long tenantId) {
        Tenant tenant = tenantRepo.getById(tenantId);
        int current = storeRepo.countByTenantId(tenantId);

        if (current >= tenant.getMaxStores()) {
            throw new QuotaExceededException(
                "门店数量已达上限 (" + tenant.getMaxStores() + ")，请升级套餐");
        }
    }

    public void checkApiQuota(Long tenantId) {
        // 基于 Redis 滑动窗口计数
        String key = "quota:api:" + tenantId + ":" + LocalDate.now();
        Long count = redisTemplate.opsForValue().increment(key);
        if (count != null && count == 1) {
            redisTemplate.expire(key, 2, TimeUnit.DAYS);
        }

        Tenant tenant = tenantRepo.getById(tenantId);
        if (count != null && count > tenant.getMaxApiCallsPerDay()) {
            throw new QuotaExceededException("今日 API 调用次数已达上限");
        }
    }
}

设计原则总结

核心原则
1. 数据隔离优先：所有业务表必须包含 tenant_id，MyBatis-Plus 拦截器自动注入，杜绝跨租户数据泄露。
2. 最小权限：RBAC + 数据范围双重控制，店长只能看本店数据，前台只能操作入住/退房。
3. 业态可扩展：策略模式封装业态差异，新增业态只需实现 IndustryStrategy 接口。
4. 功能按需开通：功能开关 + 套餐模型，租户按需付费，平台灵活运营。
5. 批量操作异步化：百台级设备操作走异步任务，进度可追踪，失败可重试。
