🐾 AgentScope Paw 详细设计

基于 Spring Boot + React 的多智能体运行平台完整设计文档，涵盖系统架构、核心模块（Bootstrap/Gateway/Session/Channel/Marketplace）、RESTful API 接口、前端组件层次、数据流设计、文件系统布局与安全机制。

← 返回文档列表
🐾 项目概述 核心概念

AgentScope Paw（内部代号 claw2）是一个基于 Spring Boot + React 构建的本地单用户 AI Agent 运行平台。它允许用户创建、配置和运行具备推理、技能、子代理和自我进化能力的 AI Agent，并通过多种外部渠道（钉钉、企业微信、飞书、GitHub、GitLab）进行消息交互。

🧠 HarnessAgent 推理 + 工具 + 子代理 + 自我进化
🔀 Gateway 路由 统一消息路由与 Turn 串行化
📡 多渠道接入 钉钉/企微/飞书/GitHub/GitLab
💾 会话持久化 JSON 文件存储，跨重启恢复
🔧 技能市场 Git/Nacos 仓库，一键安装
🖥️ React UI SSE 流式对话，工作区管理
💡 核心理念：文件系统即状态 —— 所有 Agent 状态（配置、技能、子代理、会话）均以文件形式存储在 ${claw.home} 下，便于备份、迁移和版本控制。Gateway 模式统一路由，Channel 可插拔，Session 隔离。
⚙️ 技术栈 基础设施
层级技术说明

⚡ 运行环境：Java 17+ / Node.js 18+ / 跨平台（Windows / macOS / Linux）。默认工作目录 ~/.agentscope/claw（由 claw.home 配置）。

核心设计原则

原则说明
文件系统即状态所有 Agent 状态以文件形式存储在 ${claw.home} 下，便于备份和迁移
Gateway 路由模式HarnessGateway 作为消息路由中枢，统一处理不同渠道的入站消息
会话隔离每个会话通过 canonicalKey 标识和锁定，确保同一会话 Turn 串行执行
渠道可插拔通过 ChannelTypeRegistry 注册渠道工厂，支持运行时动态添加/删除
响应式编程后端全面采用 Reactor（Mono/Flux），支持 SSE 流式响应和非阻塞 IO
🚀 启动引导模块 (ClawBootstrap) 核心入口

ClawBootstrap 是整个应用的组装入口，负责加载配置、构建 Agent、注册渠道、创建 Gateway 和 SessionManager。

▶ 构建流程
1 📁 确定 cwd 和 configPath
2 📄 加载 agentscope.json → AgentscopeConfig
3 🧠 遍历 agents 配置，构建 HarnessAgent
4 📡 解析 channels 配置，创建 Channel 实例
5 💾 创建 SessionAgentManager + SessionStore
6 🔀 创建 HarnessGateway（绑定 mainAgent + 注册 agents）

属性类型说明

registeredChannelsList<Channel>已注册渠道列表
gatewayHarnessGateway消息网关

💾 会话管理模块 生命周期

SessionAgentManager 是完整的会话生命周期管理器，构建在 DefaultAgentManager 之上，管理会话注册、Lane 并发控制、执行引擎和待完成队列。

会话类型 (SessionKind)

类型说明
MAIN主会话，由用户直接发起
SUB子代理会话，由父会话 spawn 产生

会话生命周期

创建 → 活跃 (执行Turn) → 空闲 → 自动重置 / 手动重置 → 活跃
空闲 → 空闲 → 空闲 → 超时裁剪 → 销毁

会话持久化 (SessionStore)

基于 JSON 文件 (sessions.json) 的持久化存储，读写锁保证线程安全，文件写入原子操作（先写临时文件，再 rename）。

会话生命周期调度器

触发器频率行为
每日重置配置的 dailyAt 时刻重置所有活跃会话（保留 key、所有权、标签）
空闲重置每分钟检查重置空闲超过 idleMinutes 的会话
维护清理每 5 分钟执行 runMaintenance() 裁剪旧/超量会话
📡 渠道管理模块 可插拔

通过 ChannelTypeRegistry 注册渠道工厂，支持运行时动态添加/删除渠道。内置 6 种渠道类型。

内置渠道类型

typeId实现类说明

渠道路由配置

字段说明

出站消息服务 (OutboundService)

将 OutboundRequest 转换为 OutboundAddress + Msg，通过 ChannelManager 推送消息到目标渠道。支持 Agent 工具调用（OutboundTool）和 HTTP API（OutboundController）两种触发方式。

🔌 可扩展性设计 插件化

自定义渠道

通过 ChannelTypeRegistry.register() 注册新的 ChannelFactory，在 ClawBootstrap.Builder.build() 执行前完成注册即可。

自定义工具

类型接入方式
内置工具通过 tools.allow/deny 配置启用/禁用
MCP 工具通过 tools.json 中的 mcpServers 配置接入外部 MCP 服务器
Agent 工具OutboundTool（出站消息）、SessionsTool（会话管理）自动注册

自定义模型

通过 Spring Bean 注册 Model 实例，BuilderConfig 会自动发现并使用。

技能市场

实现 ClawMarketplace 接口，注册到 ClawMarketplaceRegistry，即可在 UI 中浏览和安装技能。

Aistio 可观测性集成（可选）

通过 claw.aistio.enabled=true 启用（默认关闭），注册 AgentScopeAdapter 和 SessionBridge，向 aistiod 控制面自注册，提供 /agentscope/* 端点用于可观测性。

开发模式

# 前端开发服务器
cd frontend && npm run dev     # Vite Dev Server, port 5173

# 后端开发服务器
mvn spring-boot:run           # port 18090

# Vite 代理配置 → http://localhost:18090

生产模式

前端构建产物嵌入 Spring Boot 静态资源，单端口部署：

# 构建
cd frontend && npm run build
mvn clean package -DskipTests

# 运行
java -jar agentscope-paw.jar
# → http://localhost:18090
