全景认知

为什么需要AI智能选品

传统选品依赖经验、榜单和人工调研，爆款命中率仅约30%。AI智能选品通过整合多平台交易数据、搜索趋势和用户评价，实现从"经验驱动"到"数据驱动"的范式转变，爆款预测成功率可提升93%。

🚀 核心价值
AI选品不是替代人的判断，而是将10万+SKU的市场信号压缩为Top-20推荐列表，让人的决策聚焦在高价值环节。选品效率提升10x，新品上架到首单时间从30天缩短至7天。

核心特征详解

F1：市场需求特征（预测力最强）

  • search_volume_growth_30d：近30天搜索量环比增长率 — Google Trends
  • search_supply_ratio：搜索量/在售商品数（供需比）— 蓝海核心指标
  • bsr_velocity：BSR排名下降速度（排名下降=销量上升）— Keepa
  • google_trends_breakout：Google Trends是否出现Breakout — 爆发信号
  • new_keyword_emergence：新增相关搜索词数量 — 需求新方向
  • seasonal_index：季节性指数（历史同月销量/年均月销量）
  • tiktok_hashtag_count：相关标签视频数量 — 社交验证

F3：产品机会特征（差异化关键）

  • pain_point_density：差评痛点密度（差评中高频问题出现率）— ★★★★★
  • top_pain_category：最高频痛点类别（质量/功能/设计/服务）— ★★★★
  • improvement_feasibility：痛点改进可行性（供应链能否解决）— ★★★★
  • patent_risk_score：专利侵权风险评分 — ★★★
  • compliance_risk_score：合规风险（FDA/CE/FCC等认证需求）— ★★★★

标签定义：什么是"爆款"

🏷️ 推荐方案C：综合评分
score = 0.4×min(销量增速/50,1) + 0.3×min(毛利率/0.4,1) + 0.2×min(评价星级/4.5,1) + 0.1×max(1-退货率/0.05,0)
score ≥ 0.65 → 爆款（正样本）。综合了销量增速、毛利率、评价星级和退货率四个维度。

快速筛选规则

⚡ 排除项（命中任一即淘汰）
  • 评价垄断：单卖家评价数 > 5000且持续更新
  • 低毛利：预估毛利率 < 15%
  • 高合规风险：FDA Class III / CPSC监管品类
  • 重货：重量 > 15kg（不适合FBA）
  • 高退货率品类：品类退货率 > 15%
  • 专利高风险：专利风险评分 > 0.8
✅ 加分项（加权到最终评分）
  • Google Trends近3月增长 > 20%（+15分）
  • Top3卖家无强品牌壁垒（+10分）
  • 季节性弱，全年可售（+8分）
  • 差评痛点可通过供应链改进（+12分）
  • 1688可选供应商 ≥ 5家（+5分）

避坑指南

坑表现解决方案
数据泄露模型AUC>0.95但线上效果差严格时序CV，不用未来数据训练
品类差异服装模型直接用于3C效果暴跌按品类分组训练，或加入品类embedding
冷启动新品类/新站点无历史数据迁移学习+规则兜底+少样本学习
数据源不稳定API限流/爬虫被封/数据断供多源冗余+本地缓存+降级策略
过度依赖模型盲目信任模型，忽略合规/专利硬规则前置过滤+人工审核高风险项
特征漂移3个月前训练的模型效果下降月度自动重训练+漂移监控告警
⚠️ 最重要的一条
选品≠赚钱。选对了品但运营跟不上同样失败。AI选品必须与运营策略（Listing优化/广告投放/库存管理）联动，形成"选品→上架→运营→反馈"的完整闭环。
