海外船东数据爬虫系统

国际航运分布式大数据采集平台 — 自动化抓取30余家海外船东及口岸数据，为航运数据分析提供可靠数据底座

角色: 核心开发 领域: 大数据采集 / 分布式爬虫 规模: 30+ 海外船东

项目背景

搭建国际航运分布式大数据采集平台，自动化抓取 30 余家海外船东及口岸数据，涵盖集装箱轨迹、船期、港口记录；依托分布式爬虫完成数据清洗与标准化，为航运数据分析、货物溯源提供可靠数据底座。

🎯 核心目标
  • 自动化抓取 30+ 海外船东 及口岸数据
  • 覆盖 集装箱轨迹 / 船期 / 港口记录 三大数据类型
  • 分布式架构支撑 大规模并行抓取，保障时效性
  • 智能反爬引擎，有效规避 IP封禁 / 验证码 / 动态渲染 等反爬机制

分布式爬虫架构设计

独立从零搭建 Master-Worker 分布式爬虫架构，通过 RabbitMQ 实现任务分发、解耦调度，支持大规模并行抓取。

  • Master 节点：负责链接抓取与任务调度。从种子URL出发，深度优先遍历页面链接，提取目标列表页URL，将每条数据详情页URL封装为任务消息投递至 RabbitMQ 队列
  • Worker 节点：负责精细化数据采集。从 RabbitMQ 消费任务消息，执行页面解析、字段提取、数据清洗，写入统一数据存储
  • RabbitMQ 任务分发：Master 与 Worker 之间通过 RabbitMQ 完全解耦，Worker 可横向扩展，支持动态增减节点应对抓取压力
  • 调度策略：基于 Redis 实现任务去重（Bloom Filter），避免重复抓取；支持优先级队列，热点船东数据优先采集
// Master-Worker 分布式爬虫架构 // — Master 节点: 链接发现 + 任务分发 @Component public class CrawlMaster { @Autowired private RabbitTemplate rabbitTemplate; @Autowired private RedisTemplate redisTemplate; public void discoverAndDispatch(String seedUrl) { // 深度优先遍历，提取列表页 Queue<String> urlQueue = new LinkedList<>(); urlQueue.add(seedUrl); Set<String> visited = new HashSet<>(); while (!urlQueue.isEmpty()) { String url = urlQueue.poll(); if (visited.contains(url)) continue; visited.add(url); PageResult result = pageFetcher.fetch(url); // 提取列表页中的详情页链接 for (String detailUrl : result.getDetailUrls()) { // Bloom Filter 去重 if (!redisTemplate.opsForHyperLogLog() .add("crawler:dedup", detailUrl)) { continue; } // 投递任务到 RabbitMQ rabbitTemplate.convertAndSend( "crawler.exchange", "task.detail", new CrawlTask(detailUrl)); } // 提取下一页链接继续遍历 urlQueue.addAll(result.getNextPageUrls()); } } } // — Worker 节点: 精细化数据采集 @Component public class CrawlWorker { @RabbitListener(queues = "crawler.task.detail") public void process(CrawlTask task) { try { // 精细化数据采集 ShipData data = dataExtractor.extract( task.getUrl()); // 数据清洗 ShipData cleaned = dataCleaner.clean(data); // 写入存储 dataRepository.save(cleaned); } catch (Exception e) { // 失败重试 retryHandler.handle(task, e); } } }

爬虫内核封装

基于 Selenium 自研通用浏览器驱动，兼容 Chrome、IE、PhantomJS 多内核，支持代理切换、Cookie 状态留存、隐身访问，有效规避反爬机制。

  • 多内核兼容：基于 Selenium WebDriver 封装统一浏览器驱动接口，底层适配 Chrome（ChromeDriver）、IE（IEDriver）、PhantomJS（无头浏览器），通过配置切换无需改动业务代码
  • 代理切换：内置代理池管理，支持轮询/随机切换代理IP，单个IP请求频率超阈值自动切换，降低被封风险
  • Cookie 状态留存：登录态 Cookie 持久化至 Redis，Worker 启动时自动加载，无需重复登录，提升抓取效率
  • 隐身访问：随机化 User-Agent、禁用自动化标识（navigator.webdriver）、模拟人类操作延迟（随机等待/鼠标轨迹），有效绕过反爬检测
// 通用浏览器驱动 — 多内核兼容 + 反爬对抗 @Component public class BrowserDriverFactory { private static final String[] USER_AGENTS = { "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...", "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ...", "Mozilla/5.0 (X11; Linux x86_64) ..." }; public WebDriver create(BrowserType type) { ChromeOptions options = new ChromeOptions(); // 隐身模式 options.addArguments("--incognito"); // 随机 User-Agent options.addArguments("--user-agent=" + USER_AGENTS[ThreadLocalRandom.current() .nextInt(USER_AGENTS.length)]); // 禁用自动化标识 options.addArguments("--disable-blink-features" + "=AutomationControlled"); options.setExperimentalOption( "excludeSwitches", new String[]{"enable-automation"}); return switch (type) { case CHROME -> new ChromeDriver(options); case HEADLESS -> { options.addArguments("--headless"); options.addArguments("--disable-gpu"); yield new ChromeDriver(options); } case PHANTOMJS -> { DesiredCapabilities caps = new DesiredCapabilities(); caps.setCapability("phantomjs.page.settings" + ".userAgent", USER_AGENTS[ThreadLocalRandom.current() .nextInt(USER_AGENTS.length)]); yield new PhantomJSDriver(caps); } }; } }

数据智能处理

集成 OCR 图片识别能力解决图片验证码与图文数据采集难题，通过正则表达式完成数据清洗、去重、标准化规整，保障输出数据统一可用。

  • OCR 图片识别：集成 Tesseract OCR 引擎，自动识别图片验证码（数字+字母），解决验证码拦截问题；同时支持船东网站中嵌入的图片数据（如船期表截图、集装箱信息图片）文字提取
  • 验证码自动处理：OCR 识别失败时自动重试，多次失败触发人工审核队列，保障抓取连续性
  • 正则表达式清洗：针对不同船东数据格式差异，编写正则规则完成字段提取、格式标准化，如集装箱号格式校验（4字母+7数字）、日期格式统一（ISO 8601）
  • 数据去重与标准化：基于 Redis HyperLogLog + 业务主键双重去重，保障数据唯一性；统一数据模型映射，输出标准化数据结构
// OCR 验证码识别 @Component public class CaptchaResolver { @Autowired private Tesseract tesseract; public String resolve(byte[] captchaImage) { // 图片预处理 — 灰度化 + 二值化 + 去噪 BufferedImage processed = preprocess(captchaImage); try { return tesseract.doOCR(processed) .replaceAll("[^a-zA-Z0-9]", ""); } catch (TesseractException e) { throw new CaptchaResolveException( "验证码识别失败", e); } } private BufferedImage preprocess(byte[] raw) { BufferedImage img = ImageIO.read( new ByteArrayInputStream(raw)); // 灰度化 BufferedImage gray = new BufferedImage( img.getWidth(), img.getHeight(), BufferedImage.TYPE_BYTE_GRAY); Graphics g = gray.getGraphics(); g.drawImage(img, 0, 0, null); g.dispose(); // 二值化 + 去噪 return binarizeAndDenoise(gray); } }

稳定性优化

优化抓取策略与任务重试机制，解决网络波动、页面加载异常、IP 封禁等稳定性问题，保障 7×24 小时稳定运行。

  • 智能重试机制：网络超时/页面加载失败自动重试（指数退避：1s→2s→4s→8s），重试3次仍失败则降级为延迟重试（30分钟后重入队列），避免硬失败导致数据丢失
  • IP 代理池管理：维护代理IP可用性评分，请求失败自动标记降分，分数低于阈值移出代理池，动态补充新代理IP，保障代理可用性
  • 页面加载异常处理：Selenium 加载超时自动刷新页面重试，检测页面内容完整性（关键词匹配），内容不完整则标记为异常页面重试
  • 监控告警：抓取成功率、平均响应时间、Worker 活跃度等指标通过 Prometheus 采集，Grafana 可视化管理，异常自动告警
