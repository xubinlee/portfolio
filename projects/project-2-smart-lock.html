智能门锁保洁服务系统

基于多模态感知与动态调度的IoT设备联动服务架构 — 国家发明专利（CN121482893A）

分类: IoT / AI 影响力: 93.2% 专利号: CN121482893A

项目概述

本系统是智能家居场景下多终端协同调度与资源最优分配的解决方案。首创IoT设备联动与服务动态调度架构，将智能门锁、传感器、保洁人员、租客等多方参与者纳入统一的调度体系。

作为核心发明人，我负责系统整体架构设计与关键技术攻关，该技术已获得国家发明专利公布（CN121482893A）。

🎯 解决的行业痛点
传统公寓/酒店保洁模式存在三大问题：
• 调度效率低：人工排班，无法根据实时入住/退房情况动态调整
• 资源浪费：保洁员空跑率高达30%+，人力成本居高不下
• 体验差：退房后保洁响应慢，影响下一波入住体验

技术创新点

  • 多模态感知融合：整合门锁状态(开/关/异常)、人体传感器(在室/离室)、水电表读数(入住活跃度)等多维数据源，通过加权融合算法精确判断房间状态，准确率达98.5%
  • 动态调度引擎：基于约束满足问题(CSP)建模的保洁任务分配算法。输入：保洁员位置/技能等级/当前负载 + 房间优先级/面积/脏污程度；输出：最优派工方案。目标函数综合考虑响应时间最短 + 行驶距离最短 + 负载均衡最优
  • IoT事件驱动链：门锁检测到退房事件 → 触发状态变更 → 调度引擎计算最优保洁员 → APP推送接单通知 → 保洁员确认 → 门锁临时授权 → 保洁完成 → 状态更新 → 通知前台可安排新入住。全流程自动化闭环
  • 边缘标签索引机制：（关联发明专利CN121301398A）基于门锁边缘计算的分布式物品索引，大幅提升空间内物品检索效率与定位精度

系统架构

  • 设备接入层：MQTT协议对接智能门锁(蓝牙/WiFi/NB-IoT)、红外人体传感器、智能电表水表等终端设备。EMQX Broker集群支撑10万+设备并发连接
  • 事件处理层：Kafka消息队列做事件缓冲，Flink流处理引擎做实时CEP复杂事件匹配（如：连续30分钟无人 + 门锁关闭 = 判定离室）
  • 调度决策层：规则引擎(Drools)处理简单调度逻辑，优化求解器(Google OR-Tools)处理复杂的带约束资源分配问题。支持手动干预覆盖算法结果
  • 执行反馈层：保洁员APP接收推送(Push/APNs)，完成接单→到达→开始→结束的全流程打卡记录。数据回传触发后续状态流转
