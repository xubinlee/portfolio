Portfolio Site 源码级架构设计文档

纯静态前端站点的完整技术架构、设计模式、模块体系与工程实践深度解析 — 涵盖目录结构、主题系统、15 个功能模块、CSS 变量体系、响应式策略与无障碍设计

◆ 1. 项目全局概览

ISNOWSOFT Portfolio Site 是一个纯静态前端站点，零构建依赖，零框架依赖，双主题自适应，涵盖 12 个项目展示与 21 篇深度技术文档。整个站点由原生 HTML + CSS + JavaScript 构建，不依赖 React/Vue/Angular 等任何前端框架，也不依赖 Webpack/Vite 等任何构建工具。

🎯 核心设计哲学
  • 零依赖原则 — 不引入任何 npm 包，不使用任何构建工具，所有代码均为手写原生实现
  • 渐进增强 — 基础内容在任何浏览器可访问，高级动效在支持的环境中渐进增强
  • 双主题一致性 — 通过 CSS 变量体系实现暗色/亮色主题的无缝切换，杜绝硬编码色值
  • 无障碍优先 — ARIA 标签、键盘导航、减弱动画适配，确保所有用户可访问
  • 语义化架构 — 使用 header/main/nav/article/section 等语义标签构建信息层次

2.2 页面自包含策略

⚠️ 设计权衡：内联 vs 外联

docs/ 和 projects/ 子页面采用内联样式+内联脚本策略：

  • 优势：每个页面完全自包含，可独立打开、独立部署，不存在跨目录路径问题
  • 优势：避免 CDN 缓存失效问题，每个页面的样式/脚本与内容强绑定
  • 代价：主题切换逻辑、导航栏样式等存在一定程度的代码重复
  • 缓解：通过 README.md 中的开发约定规范，确保重复代码的一致性

5.3 关键模块深度解析

5.3.1 Neural Background — 粒子网络系统

这是站点的视觉核心，基于 Canvas 2D 实现的神经网络粒子背景：

function Particle() { this.x = Math.random() * canvas.width; this.y = Math.random() * canvas.height; this.vx = (Math.random() - 0.5) * 0.5; // 速度 [-0.25, 0.25] this.vy = (Math.random() - 0.5) * 0.5; this.radius = Math.random() * 2 + 1; // 半径 [1, 3] } // 核心渲染循环 function animate() { ctx.clearRect(0, 0, canvas.width, canvas.height); for (var i = 0; i < particles.length; i++) { var p = particles[i]; p.x += p.vx; p.y += p.vy; if (p.x < 0 || p.x > canvas.width) p.vx *= -1; if (p.y < 0 || p.y > canvas.height) p.vy *= -1; // 鼠标排斥（150px范围） var dx = mouseX - p.x, dy = mouseY - p.y; var dist = Math.sqrt(dx*dx + dy*dy); if (dist < 150) { p.x -= dx*0.01; p.y -= dy*0.01; } // 绘制粒子 ctx.beginPath(); ctx.arc(p.x, p.y, p.radius, 0, Math.PI*2); ctx.fillStyle = "rgba(0, 212, 255, 0.4)"; ctx.fill(); // 粒子间连线（距离 < 120px，透明度衰减） for (var j = i+1; j < particles.length; j++) { var ddist = Math.sqrt(ddx*ddx + ddy*ddy); if (ddist < 120) { ctx.strokeStyle = "rgba(0,212,255,"+(0.15*(1-ddist/120))+")"; ctx.stroke(); } } } requestAnimationFrame(animate); }
💡 性能优化策略
  • 粒子数自适应：window.innerWidth < 768 ? 30 : 60
  • 连线算法优化：内循环从 j = i+1 开始，避免重复绘制
  • 连线透明度衰减：0.15 * (1 - dist/120)，距离越远越透明
  • reduced-motion 适配：检测到用户偏好后直接 return

◆ 12. 安全考量

🔒 安全设计要点
  • XSS 防护：AI Chat 模块中所有用户输入通过 escapeHtml() 函数处理，使用 document.createTextNode() 而非 innerHTML 直接插入
  • 无服务端依赖：联系表单通过 mailto: 协议发送，不暴露任何 API 端点
  • 无敏感信息：电话号码部分掩码（159********），无 API Key 或 Token 泄露
  • Content-Security-Policy：纯静态站点，所有资源同源，无外部脚本依赖
  • localStorage 安全：仅存储主题偏好（非敏感数据），无用户隐私信息

◆ 13. 浏览器兼容性

浏览器最低版本核心依赖 API
Chrome80+CSS Custom Properties、CSS Grid、backdrop-filter
Firefox78+Canvas API、localStorage、IntersectionObserver
Safari14+-webkit-backdrop-filter、mask-composite
Edge80+同 Chrome（Chromium 内核）
💡 降级策略
  • backdrop-filter 不支持时，Header 背景变为半透明纯色
  • mask-composite 不支持时，全息边框效果不显示（不影响功能）
  • IntersectionObserver 不支持时，滚动动画和进度条直接显示最终状态
  • Canvas 不支持时，粒子背景和雷达图不渲染（不影响内容）

◆ 16. 架构总结

ISNOWSOFT Portfolio Site 是一个极致简约但功能完备的纯静态前端站点。其架构设计的核心价值在于：

🏆 架构核心价值
  • 零依赖的工程勇气 — 在框架横行的时代，用原生技术栈构建出具备粒子动画、雷达图、AI对话等复杂交互的站点，证明了原生 Web API 的强大能力
  • CSS 变量驱动的双主题 — 30+ CSS 变量 + data-theme 属性选择器 + localStorage 持久化 + storage 事件跨标签页同步，构成完整的主题基础设施
  • IIFE 模块化 — 15 个功能模块在 IIFE 内独立定义、统一初始化，既避免了全局污染，又保持了代码的可读性和可维护性
  • 渐进增强的交互策略 — IntersectionObserver 替代 scroll 监听、Canvas 动画在 reduced-motion 时停止、移动端粒子数减半，处处体现性能意识
  • 无障碍优先的设计 — ARIA 标签、键盘导航、Skip Link、减弱动画适配，确保技术文档站对所有用户可访问
  • 终端美学的视觉语言 — 从品牌标识 <ISNOWSOFT.DEV/> 到导航 ./home，从 CTA [ run ./connect.sh ] 到 AI 对话窗口，统一的终端风格贯穿全站

这个站点不仅是一个作品集展示平台，更是一份用代码书写的架构宣言 — 证明了一个优秀的前端工程不一定要依赖复杂的框架和构建工具，原生 Web 平台本身就足够强大。
